# Connect Sentinely

1. Start the Sentinely connection from Codex and complete the OAuth flow in the browser.
2. Review the Sentinely account and workspace shown on the consent screen before authorizing.
3. Return to Codex and ask what people are saying about your brand this week to confirm the connection.

Never ask the user to paste a password, access token, OAuth code, or browser cookie into chat or
configuration. If authorization fails, report the visible error and direct the user to Sentinely
support. Do not switch accounts or workspaces without the user's choice.
